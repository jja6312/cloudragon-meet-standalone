# 독립판 검증 기록

확인일: 2026-10-30 UTC. 실행 환경: Linux ARM64, Node 22.13.1 및 24.19.0. 브라우저: Playwright 1.63.0의 Chromium, 가상 마이크와 합성 전사·AI 응답.

- `npm run build`: TypeScript와 Vite 7.3.7 프로덕션 빌드 통과.
- `npm test`: **12/12 통과, 건너뜀 0**. Node 22.13.1과 24.19.0에서 각각 확인했다. 자체 계정·세션·CSRF·Host/출처·공간/파일 경계, 조각 재전송·충돌·연속 순번, 종료 전사·범위 재생·삭제, 다른 기록 보존, AI 원문 보존/수정 충돌/삭제 중 완료/제공자 오류 숨김, TTS 언어, 재시작 상태, 설정 생성·변경과 해시·권한을 검증한다.
- `npm run test:browser`: **3/3 통과**. 로그인 → 실제 MediaRecorder 녹음 → 종료 직전 확정 전사 → 비동기 AI 완료 → 사람 편집 → 새로고침 후 보존 → 범위 음성 응답 → 삭제를 확인했다. 저장 취소 확인창의 취소/수락, 390px 화면 폭과 `d` 단축키도 확인했다.
- `npm run check:secrets`: 공유 경로·빈 설정 견본·운영 호스트 의존성 검사 통과. 독립 Git 이력이며 운영 키·데이터·기존 APK는 포함하지 않는다.
- `npm audit`: 전체 의존성의 보고된 취약점 **0건**(확인 시점 기준). 처음 추출한 Vite 7.1.7의 보고된 취약점을 확인하여 독립판만 7.3.7로 갱신했다. 이후 새 취약점이 없음을 보장하는 수치는 아니다.

초기 시험에서 두 검증 구성 문제를 수정했다. Node fetch가 임의 Host 헤더를 보존하지 않아 raw HTTP 요청으로 Host 거절을 확인했다. 브라우저 WebSocket 가로채기를 페이지 로드 전에 등록하여 전사 시험이 실제 제공자로 나가지 않게 했다. 이전 실패 실행을 통과 수에 포함하지 않았다.

실제 Soniox/OCI/OpenAI 키로 유료 요청을 실행하지 않았다. 음성 인식·번역·요약의 실제 품질, 해당 계정의 모델 사용 권한, Galaxy 잠금/절전, 장시간 9시간 운용, 외부 TLS/Windows 설치와 Docker 컨테이너 기동은 미검증이다. Docker가 없는 개발 호스트에서 이미지를 만들거나 시스템 서비스를 변경하지 않았다.

이번 결과는 별도 저장소의 코드 전달과 로컬 검증이다. 원래 Cloudragon 운영 사이트·DB·Android 앱 배포 상태의 변경을 의미하지 않는다.
